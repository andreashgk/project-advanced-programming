Project Advanced Programming 2022-2023
=======================================

This was my submissions for the project in the course "Advanced Programming" during my bachelor.
The requirement for this project was to implement a game like "meat boy" in C++, with SFML and using certain specific programming patterns.
The project was developed on a repository made by the school which I no longer have access to, and as such I no longer have the git history.
For clarity this commit has been backdated.
